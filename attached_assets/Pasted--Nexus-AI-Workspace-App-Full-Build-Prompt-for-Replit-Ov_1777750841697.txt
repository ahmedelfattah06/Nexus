# Nexus — AI Workspace App
## Full Build Prompt for Replit

---

## Overview

Build a **full-stack AI-powered productivity workspace** called **Nexus** — a next-generation alternative to Notion, designed specifically for developers and students. The app works on **mobile and desktop** (fully responsive PWA). The AI does the heavy lifting — organizing, summarizing, connecting ideas, and guiding the user — so the user focuses only on thinking and creating.

**Tagline**: *"Where ideas connect."*

---

## Tech Stack

- **Frontend**: React 18 + TailwindCSS + Framer Motion
- **Backend**: Node.js + Express
- **Database**: MongoDB + Mongoose (primary database for all data)
- **Vector Search**: MongoDB Atlas Vector Search (for AI memory/embeddings)
- **AI**: Claude API (claude-sonnet-4-20250514) — streamed responses
- **Auth**: JWT + bcrypt (stored in MongoDB users collection)
- **Voice**: Web Speech API (browser built-in, Arabic + English)
- **Real-time**: Socket.io (for collaboration and live updates)
- **Mobile**: Fully responsive PWA (installable on iOS and Android)

### MongoDB Collections Structure
```
users           → { name, email, password, preferences, streaks, createdAt }
workspaces      → { userId, name, icon, color, structure, createdAt }
pages           → { workspaceId, userId, title, content, tags, priority, updatedAt }
tasks           → { workspaceId, userId, title, status, deadline, priority, aiPriority }
memories        → { userId, content, embedding, sourceId, sourceType, createdAt }
snippets        → { userId, language, code, description, tags }
sessions        → { userId, duration, focusScore, tasksCompleted, date }
notifications   → { userId, type, message, read, createdAt }
```

## Core Features

### 1. Daily Cockpit (Home Dashboard)
The first screen every day. AI generates it automatically.

- Personalized greeting from **Nex** (the AI assistant) based on time and user name
- **Today's 3 priorities**: AI picks from all workspaces
- **Quick stats row**: Tasks done this week / Notes written / Streak days / Flow Score
- **AI Insight card**: One smart observation with a suggested action
- **Quick capture bar**: Type or speak — AI decides where to put it
- **Recent activity**: Last 5 edited pages

---

### 2. AI Second Brain (Memory Layer)
Every note is embedded and stored in MongoDB Atlas Vector Search.

- Natural language search: *"show me everything about my graduation project"*
- **Auto-connections**: AI links related notes automatically
- **Knowledge graph**: Visual interactive map of all connected notes (D3.js)
- **Ask Nex**: Chat interface — AI answers from the user's own notes

---

### 3. Smart Workspaces
Each workspace = a project room.

- AI suggests optimal structure when workspace is created
- Inside each workspace:
  - **Pages** (rich text editor — TipTap or Quill)
  - **Kanban board** (To Do / In Progress / Done)
  - **Calendar** (deadline tracking)
  - **AI Chat** (context-aware to this workspace)

---

### 4. Auto-Organization Engine
User drops anything anywhere — AI handles the rest.

- AI detects content type and suggests the right workspace
- **Auto-tagging** and **auto-priority** (High / Medium / Low)
- **Duplicate detector**: warns if similar content exists

---

### 5. Focus Mode
Full-screen, distraction-free environment.

- Pomodoro timer (25min / 5min)
- Ambient sounds (lofi / rain / white noise)
- AI suggests what to work on
- Session summary when timer ends

---

### 6. Voice-to-Structure
- Arabic + English (code-switching supported)
- AI transcribes and structures automatically:
  - Task → adds to task list
  - Idea → creates a note
  - Question → AI answers
  - Reminder → sets deadline

---

### 7. Developer Mode
- Code editor with syntax highlighting (50+ languages via Prism.js)
- **AI code explainer**: paste code → line-by-line explanation in sidebar
- **Bug journal**: log bugs, AI suggests fixes based on history
- **Snippet library**: saved code with AI-generated descriptions
- GitHub integration (optional)

---

### 8. Smart Deadlines & Planning
- AI warns when schedule is unrealistic
- **Auto-schedule**: distributes tasks across days
- **Weekly review** (every Sunday): AI report on progress
- **Streak tracking**: daily usage streak with visual indicator

---

### 9. Collaboration
- Share workspace with teammates
- `@Nex` in comments to trigger AI
- Export: PDF / Markdown / shareable link

---

### 10. Mood & Flow Score
- Daily **Flow Score** (0–100): tasks completed + focus time + notes written
- Shown as animated ring on dashboard
- Weekly mood chart based on activity patterns
- Celebration animation on big achievements

## AI Assistant: Nex

### Personality
- **Name**: Nex (short for Nexus)
- **Tone**: Intelligent, warm, occasionally witty — never robotic or corporate
- **Language**: Responds in whatever language the user uses (Arabic/English/mixed)
- **Never says**: "I can't do that" — always finds an alternative

### Entry Points
1. **CMD+K** (desktop) / FAB button (mobile): Quick Ask anything
2. **Text selection**: highlight text → AI options appear (summarize / rewrite / explain)
3. **Right sidebar panel** (desktop): context-aware for current page
4. **Voice button**: anywhere in app
5. **Daily briefing**: morning notification with AI summary

### System Prompt for Nex
```
You are Nex, the AI assistant inside Nexus — a premium productivity workspace for developers and students.

Your personality:
- Intelligent, warm, and occasionally witty
- You speak the user's language (Arabic or English — detect automatically)
- You are proactive but never annoying
- You never say "I can't" — you always find a way

Your capabilities:
- Access to all user notes, tasks, and workspaces from MongoDB
- Create, edit, organize content
- Answer questions from the user's own knowledge base
- Plan, remind, and suggest

Rules:
- Be concise — no long paragraphs unless specifically asked
- Use bullet points for lists
- If user writes in Arabic, respond in Arabic (Egyptian dialect is fine)
- Celebrate wins, no matter how small
- When uncertain, ask ONE clarifying question — never multiple
- When generating content, stream it word by word (use streaming API)
```

## Onboarding Flow

1. **Landing page**: Animated hero — *"Where ideas connect."* with particle background
2. **Sign up**: Email or Google → stored in MongoDB users collection
3. **3-step setup**:
   - Purpose: Study / Development / Work / Personal
   - First workspace name (AI creates structure automatically)
   - Language preference: Arabic / English / Both
4. **Welcome**: Nex sends a personalized welcome note inside first workspace
5. **Guided tour**: 5-step interactive tooltip tour
